## Key Learning

* Strings are sequences of characters and are immutable.
* `.split()` converts a string into a list, while `.join()` combines strings from a list.
* `.format()` makes it easier to build strings containing different types of values.
* Dictionaries store data as key-value pairs and can be modified using their keys.
* Modules allow Python functionality from libraries to be imported and reused.
* `type()` tells us what kind of object we're working with.
* `dir()` shows the attributes and methods available on an object.
* `help()` provides documentation about functions, methods, and objects.
* Different libraries can create their own object types with their own behavior.
* Operator overloading allows operators such as `+`, `<`, `==`, `in`, and `[]` to behave differently depending on the object.
* NumPy arrays demonstrate how operators can work differently from normal Python lists.
