## Key Concepts

* **Individuals** → The objects or entities represented by each row in a dataset.
* **Variables** → Characteristics or measurements recorded for each individual.
* **Categorical variables** → Values that belong to distinct categories, such as `Hot` or `Cold`.
* **Quantitative variables** → Numerical values that represent measurements, such as calories, sugar, or caffeine.
* **Mean** → Sum of all values divided by the number of values.
* **Median** → The middle value when data is arranged in order.
* **Mode** → The most frequently occurring value.
* **Range** → Highest value − Lowest value.
* **Midrange** → (Highest value + Lowest value) / 2.
